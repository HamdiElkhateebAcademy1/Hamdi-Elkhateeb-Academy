# Hamdi Elkhateeb Academy — English Redesign

This is a ready-to-upload static website package based on the old dark-blue academy style shown in the supplied screenshots.

## Included
- Responsive English interface
- Old-style dark blue visual direction with rounded cards
- Supplied cover image
- Supplied instructor image
- Three supplied dental/course images
- Working navigation and mobile menu
- Search panel with course filtering
- Course/resource modal interactions
- Courses, lectures, resources and about sections
- No external libraries or dependencies

## Install on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository that serves the academy website.
2. Keep the `assets` folder beside `index.html`.
3. Commit/push the changes.
4. GitHub Pages will serve `index.html`.

## Important
The visual/interactive shell is complete, but real student login, database accounts, course enrollment, video hosting, certificates and downloadable files need to be connected to the services/data used by the existing platform. The current buttons provide working UI feedback rather than pretending those backend systems already exist.

If the existing site already has course/database code, merge this front-end into that code instead of deleting the backend.
