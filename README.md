# Hamdi Elkhateeb Academy
واجهة Dashboard أولية للطالب باللغة العربية RTL.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## المرحلة التالية
هذه نسخة Frontend تجريبية فقط. لإطلاق منصة حقيقية نضيف:
- Backend وقاعدة بيانات
- تسجيل دخول وحسابات الطلاب
- شراء واشتراكات
- فيديوهات ودروس مقفولة حسب الاشتراك
- لايف وروابط المحاضرات
- رفع الواجبات والملفات
- شهادات
- لوحة تحكم Admin
- بوابة دفع
