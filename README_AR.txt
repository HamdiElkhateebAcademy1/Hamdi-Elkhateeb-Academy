Hamdi Elkhateeb Academy - Android APK

هذه النسخة مجهزة لإخراج APK موقّع تلقائياً من GitHub Actions.

طريقة التشغيل من الهاتف:
1) أنشئ مستودع GitHub جديد.
2) ارفع كل ملفات ومجلدات هذا المشروع إلى الفرع main.
3) افتح تبويب Actions.
4) اختر: Build Hamdi Academy APK
5) اضغط Run workflow.
6) بعد نجاح البناء افتح العملية الناجحة.
7) من Artifacts حمّل Hamdi-Academy-APK.
8) فك الضغط وستجد app-debug.apk.
9) افتح APK على هاتف Android وثبّته.

ملاحظة:
- ملف app-debug.apk موقّع بتوقيع Debug الرسمي الخاص بأداة Android، لذلك يمكن تثبيته مباشرة للاختبار والتوزيع اليدوي.
- التطبيق يفتح منصة Hamdi Elkhateeb Academy الحالية من GitHub Pages داخل WebView.
- يحتاج التطبيق إلى الإنترنت لأن المنصة وSupabase يعملان عبر الإنترنت.
- هذه نسخة Android. لا يمكن تثبيتها على iPhone.
